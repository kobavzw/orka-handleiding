<ImageTitle img="login.png">Toegang tot ORKA</ImageTitle>

Een gebruiker kan inloggen in Toolbox via volgende URL https://orka.kobavzw.be/.

![login1](./login1.png)

Door te klikken op 'Microsoft Login' kan je gebruik maken van je Microsoft credentials van de regio of school. Ben je reeds ingelogd bij Microsoft, dan zal je geen credentials meer moeten ingeven. Je komt rechtstreeks in ORKA terecht.
